
# 🎥 Netflix Movies & TV Shows Exploratory Data Analysis (EDA)

## 📄 Project Overview
This project explores the Netflix Movies and TV Shows dataset to uncover insights about the content available on Netflix. The analysis is performed using Python in a Jupyter Notebook, focusing on content types, genres, countries, durations, ratings, and trends over time.

## 🗂️ Dataset
- **Source:** [Kaggle - Netflix Movies and TV Shows Dataset](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- **File:** `netflix_titles.csv`
- **Description:** Contains information on movies and TV shows available on Netflix as of 2021. Columns include show ID, type, title, director, cast, country, date added, release year, rating, duration, genres, and description.

## 🎯 Objectives
- Understand the distribution of content types (Movies vs. TV Shows).
- Analyze content by countries, genres, and ratings.
- Explore trends in content addition over time.
- Investigate movie durations and common genres.

## 🔧 Tools & Libraries
- Python 🐍

## 📊 Key Analysis and Visualizations
- ✅ Distribution of Movies vs. TV Shows.
- ✅ Top countries contributing to Netflix content.
- ✅ Analysis of content ratings.
